# Security Policy

## Reporting a Vulnerability

The Boat Cleaning Website project takes security concerns seriously.

If you discover a potential security vulnerability, please report it responsibly so it can be reviewed and addressed.

Please follow these steps:

1. Visit the repository's GitHub Security tab:
   https://github.com/cjsantizo/Boat-Cleaning-website/security
2. If the **Report a vulnerability** option is available, use it to submit a private vulnerability report.
3. Include a description of the issue, steps to reproduce it, and any relevant details that may help investigate the problem.
4. Please avoid publicly disclosing security vulnerabilities before they have been reviewed.

If private vulnerability reporting is unavailable, contact the repository owner through their GitHub profile:
https://github.com/cjsantizo

## Supported Versions

This project is an older website implementation. Security updates and maintenance are not guaranteed for every version.

## Response

Reported vulnerabilities will be reviewed when possible. There is no guaranteed response or resolution timeframe.
