# Contributing to Boat Cleaning Website

Thank you for your interest in contributing to this project.

## How to Contribute

1. Fork this repository.
2. Create a new branch for your change.
3. Make your changes and test them locally by opening `index.html` in a browser.
4. Open a pull request against the `main` branch with a clear description of what you changed and why.

## Requirements for Acceptable Contributions

- Code must use plain HTML5, CSS3, and JavaScript (no frameworks or build tools).
- Keep styling in `boatstyle.css` and scripts in `boatFunction.js`. Do not use inline scripts or styles for new features.
- Use clear, descriptive names and consistent 2- or 4-space indentation matching the existing files.
- Do not commit secrets, API keys, passwords, or server-side code.
- Changes must not break existing pages (`index.html`, `gallery.html`, `thankyou.html`).
- All changes are submitted through pull requests and reviewed before merging.

## Reporting Bugs

Open an issue at https://github.com/cjsantizo/Boat-Cleaning-website/issues with steps to reproduce the problem.

## Reporting Security Issues

Please do not open public issues for security problems. Follow the instructions in [SECURITY.md](SECURITY.md).
