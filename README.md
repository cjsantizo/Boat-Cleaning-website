# Boat Cleaning Website

**Live Website:** [https://boatcleaningfl.com/](https://boatcleaningfl.com/)

[![OpenSSF Scorecard](https://api.scorecard.dev/projects/github.com/cjsantizo/Boat-Cleaning-website/badge)](https://scorecard.dev/viewer/?uri=github.com/cjsantizo/Boat-Cleaning-website)

## Project Overview

Boat Cleaning Website is a business website developed using **HTML, CSS, and JavaScript** to showcase professional boat cleaning services.

The website provides visitors with information about the business, available services, before-and-after cleaning results, and ways to contact the business.

The frontend includes a parallax-style homepage, smooth scrolling navigation, an interactive before-and-after image comparison slider, a separate photo gallery, and an embedded Google Maps location.

**Note:** This repository contains the frontend portion of the website. The backend and server-side functionality are hosted separately through SiteGround and are not included in this public repository.

## Main Goal

The goal of this project was to develop a professional and user-friendly website that helps a boat cleaning business establish an online presence, promote its services, showcase completed work, and provide customers with a convenient way to contact the business.

My focus was on developing and maintaining the frontend, organizing website content, implementing interactive features, and ensuring visitors could easily navigate the website.

## Features

- **Responsive Website Layout:** Designed to support viewing the website across different screen sizes.
- **Parallax Hero Section:** A homepage featuring a parallax-style background image.
- **Smooth Scrolling Navigation:** Navigation links that smoothly scroll between the Home, Services, About, and Contact sections.
- **Services Section:** Displays information about the boat cleaning services offered.
- **Photo Gallery:** A separate gallery page showcasing the business's work.
- **Before-and-After Comparison Slider:** An interactive draggable image slider allowing visitors to compare cleaning results.
- **Contact Section:** Includes a contact form and clickable contact information.
- **Google Maps Integration:** An embedded interactive map displaying the business location.
- **Google Analytics:** Integrated analytics to help track website visitor activity.

## Technologies Used

- **HTML5:** Website structure and page content.
- **CSS3:** Website styling, layout, and visual presentation.
- **JavaScript:** Interactive features, navigation behavior, and image comparison functionality.
- **Google Maps:** Embedded business location map.
- **Google Analytics:** Website traffic analytics.
- **SiteGround:** Website hosting and management of the deployed server-side functionality.

## How to View and Run the Project

There are two ways to explore this project: visit the live website or download the frontend source code to review and run it locally.

### Option 1: Visit the Live Website (Recommended)

The completed website is publicly accessible online.

**Live Website:** [https://boatcleaningfl.com/](https://boatcleaningfl.com/)

Visitors can explore the homepage, view available services, browse the photo gallery, interact with the before-and-after comparison slider, and access the contact section and Google Maps integration.

No installation or development tools are required to visit the website.

### Option 2: Open the Project in an IDE

Developers and recruiters interested in reviewing the frontend source code can download the repository and open it using an IDE or code editor, such as Visual Studio Code.

**Step 1: Download the Repository**

Clone the repository using Git:

```bash
git clone https://github.com/cjsantizo/Boat-Cleaning-website.git
```

Alternatively:

1. Click the green **Code** button on this GitHub repository.
2. Select **Download ZIP**.
3. Extract the ZIP file to your computer.

**Step 2: Open the Project in Visual Studio Code**

1. Install [Visual Studio Code](https://code.visualstudio.com/) if needed.
2. Launch Visual Studio Code.
3. Select **File → Open Folder**.
4. Navigate to the downloaded `Boat-Cleaning-website` folder.
5. Open the folder to explore the frontend source files.

**Step 3: Run the Frontend Locally**

1. Locate `index.html` in the project folder.
2. Open it in a web browser, or use the **Live Server** extension in Visual Studio Code to launch a local preview.
3. Navigate through the website and test its frontend features.
4. Open `boatstyle.css` and `boatFunction.js` to explore the website's styling and JavaScript functionality.

**Important:** The local version contains only the frontend. Server-side functionality, including contact form processing, requires the live hosting environment.
